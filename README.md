# Овощная битва — Veggie Battle Royale

Играбельный прототип батл-рояля на Three.js, спроектированный так, чтобы
игровую логику было легко перенести на Luau/Roblox.

## Запуск

```bash
npx serve .            # или: python -m http.server 8000
# открыть http://localhost:8000
```

Любой статический сервер из корня проекта подойдёт — `three` уже
завендорен в `vendor/`, собирать и ставить зависимости не нужно,
интернет тоже. Сборки нет: index.html + ES-модули + статика.

Подробности архитектуры и разработки — в `DEVELOPMENT.md`.

## Управление

| Ввод | Действие |
|------|----------|
| Клик по экрану | захват мыши (pointer lock) / старт |
| WASD | бег (относительно камеры) |
| Shift | ускорение |
| Space | прыжок (на блоки можно запрыгнуть) |
| Мышь | обзор, ЛКМ — выстрел |
| 1 / 2 | оружие: овощемёт / хламомёт |
| Колесо мыши | переключение оружия |
| E | пнуть бак (пока рядом враг-бак) |
| R | рестарт |

## Правила

- Старт матча — десант: все падают с высоты под парашютом в виде
  семейных трусов или лифчика (левая/правая сторона — случайно).
  WASD работает и в воздухе, можно сесть на крышу руины.
- Вид от первого лица; 11 капсул на плоской карте 220×220, собранной из
  кубов 1×1×1 м как в Minecraft: текстурированные блоки травы, земли,
  песка и кирпича. Две гравийные дороги крестом через центр, деревья
  со стволами и кронами, большая руина-дом, колодцы, сторожевые башни,
  песчаные лестницы, земляные курганы, травяные столбы. Бока кубов —
  стены, верх — пол, на них можно запрыгнуть; выстрелы они блокируют.
- Боты дерутся по-умному: стрейфят вокруг цели и держат дистанцию
  8–20 м, раненые бегут к тостам за хилом, застрявшие прыгают через
  блоки, за край зоны не уходят.
- Два ствола (1/2 или колесо): «Овощемёт» стреляет случайным овощем —
  помидор, огурец, банан, брокколи, морковь или картофель; «Хламомёт» —
  бытовым хламом и это четырёхствольный дробовик: залп — полный
  столовый набор (тостер, кофеварка, вилка, ложка) с разбросом; каждый
  прилипший кусок даёт 2 очка, двух выстрелов в упор хватает на бак.
  У овощемёта патроны отличаются только видом, урона как такового нет:
  каждое попадание ПРИЛИПАЕТ к цели (снаряды видны на теле). У обоих
  стволов — GLB-модели из `assets/models/`, точка выстрела на срезе
  дула; хлам тяжелее и летит по более крутой дуге.
- 10 очков прилипаний (овощ = 1, кусок хлама = 2) — и жертва
  превращается в бак: овощами добили — в БАК С ОВОЩАМИ, хламом
  добили — в БОЛЬШОЙ ТОСТЕР. Пнёте тостер (E) — из него вылетают
  4 ломтика тоста: наступите на ломтик — +14 HP (боты тоже хватают).
  Бак — кубический, в стиле майнкрафта; тостер — большой хромовый.
  Подойдите и пните (E) — бак/тостер взлетает вверх, а враг умирает.
  Не пнули за 3 секунды — враг вылезает обратно с половиной HP.
  Боты сами ходят пинать баки!
- У всех по 3 жизни. Смерть → БАЛКОН: три отдельные каменные
  платформы-дуги кольцом на высоте 30 м (над верхом стены зоны) —
  стена сжимается ПОД ними, платформа не деформируется. 30 секунд
  ожидания — и обратно в бой на бельевом парашюте. На каждой платформе
  по 2 снайперские пушки с дулами над краем: подойдите (E) — оптический
  прицел (зум), ЛКМ — выстрел слизью. Слизь ПРИПЕЧАТЫВАЕТ жертву на
  месте на 5 секунд. Боты на балконе сами садятся за пушки и
  снайперят бегающих внизу.
- В воздухе под парашютом стрелять нельзя. Промахи и вспышки не
  рисуются — попадание видно по прилипшему овощу на теле.
- Красная зона сжимается со временем; снаружи — урон в секунду.
- Боты бродят внутри зоны и отстреливаются (и друг по другу).
- Побеждает последний уцелевший.

## Архитектура (logic / view)

```
src/logic/   чистая симуляция — БЕЗ импортов three и DOM
  vec3.js      математика на plain {x,y,z}
  config.js    все константы баланса
  raycast.js   swept-тесты: segmentSphere / segmentGround / segmentAABB
  weapon.js    слоты оружия: «Овощемёт»/«Хламомёт», спавн снарядов
  bin.js       механика бака: stickVeggie/tickBin/kickBin/tryKick
  bots.js      ИИ ботов
  world.js     state + step(state, input, dt) — единственный мутатор
src/view/    Three.js-представление
  main.js      цикл с фиксированным dt, склейка слоёв
  sceneView.js меши, воксельные текстуры, эффекты, камера 1-го лица
  hud.js       DOM-интерфейс
  input.js     сбор ввода -> engine-free пакет {mx,mz,aim,...}
```

Хит-детекция — raycast-подход: каждый тик снаряд пролетает отрезок
`prev -> pos`, который проверяется `segmentSphere` против целей,
`segmentGround` и `segmentAABB` против блоков; берётся ближайшее `t`.
На Roblox это заменяется `workspace:Spherecast`/`Raycast` за Heartbeat.

Подробная карта переноса — в `.devin/skills/roblox-luau-port/SKILL.md`.

## Headless-хуки

`window.render_game_to_text()` — JSON снимок состояния;
`window.advanceTime(ms)` — детерминированный прогон симуляции.

## Мультиплеер

Лобби по коду комнаты: ник + код → «В лобби». Матч стартует через
60 секунд после первого игрока, недостающие места добиваются ботами
(всего 11 сущностей). Первый зашедший — хост: у него крутится вся
симуляция и боты; остальные шлют ввод и получают снапшоты 12 Гц.

Релей — `server/lobby_server.py` (python3 + websockets, порт 8791).
Публичный эндпоинт: `wss://kapitanpiho.duckdns.org/veggie-ws` (Caddy).
Локально: `py -3 server/lobby_server.py` → `ws://localhost:8791`.
